# OpenClaw

OpenClaw is the open execution layer for Tahcia-based automation workflows.

Designed for:

- AI agents
- browser automation
- desktop workflows
- script execution
- automation orchestration

## Capabilities

- browser interaction
- desktop control
- workflow execution
- automation primitives
- script interoperability
